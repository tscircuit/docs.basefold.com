# Basefold Docs

Welcome to the Basefold documentation.

Use this site to publish guides, references, and architecture notes.

## What is included

- Docusaurus v3 with TypeScript config
- Autogenerated docs sidebar from the `docs/` tree
- Shared markdown source export plugin used in the tscircuit docs stack
- Bun-first scripts and Biome formatting conventions

## Next steps

1. Add your first guide under `docs/`.
2. Run `bun run start` and verify local navigation.
3. Update navbar/footer links in `docusaurus.config.ts` for production.
